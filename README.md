# 32-bit-Single-Cycle-RISC-V-RV32I-Processor-Verilog-RTL-Design-Verification
A 32-bit single-cycle RISC-V RV32I processor designed and verified in Verilog. Implements R-, I-, S-, and B-type instructions with a complete datapath, control unit, ALU, register file, and memory interfaces. Verified using QuestaSim, with ongoing work towards RTL-to-chip implementation.
